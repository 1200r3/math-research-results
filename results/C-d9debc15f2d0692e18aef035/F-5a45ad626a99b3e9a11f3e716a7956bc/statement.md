# One-monomino stabilization in near-square tatami rectangles

For positive integers n and d, let T(n,n+d,1) count labelled-grid tilings by 1-by-2 dominoes and exactly one 1-by-1 monomino, with no four tile corners meeting. We do not quotient by reflection or rotation.

- If d is odd, T(n,n+d,1)=0 for every n; there is no parity-admissible n.
- For d=2, T(5,7,1)=8 and T(n,n+2,1)=4 for every odd n>=7, with exactly one tiling for each monomino corner. The least parity-admissible stabilization anchor is 7; the least integer cutoff for a stable odd subsequence is 6.
- For even d>=4, T(d+3,2d+3,1)=4 and T(n,n+d,1)=0 for every odd n>=d+5. The least parity-admissible stabilization anchor is d+5; the least integer cutoff for a stable odd subsequence is d+4.

In both even-d cases the counts at even n are zero. A stabilization anchor is itself parity-admissible; a cutoff is merely an integer lower bound for all parity-admissible terms that follow it. This is a literature-based corollary for one monomino and does not settle the general fixed-m conjecture.
