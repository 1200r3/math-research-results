**Binding and scope.** I verified all seven requested materials against their SHA-256 hashes and the sealed package. I compared the exact statement, the TeX proof, and the mathematical text in the PDF. The statement includes the explicit lower bound for every integer n ≥ 9; this follows by the same restriction argument used for orders 9–12. The definition treats the palette as a set of available colors, allows two vertices of a triangle to have the same color, and excludes monochromatic equilateral triangles of every size and orientation.

**R1 — Geometry (proof §1; verifier geometry).** With unit basis vectors at 60°, the squared length of (u,v) is u²+uv+v². Rotation by +60° maps the first basis vector to the second and the second to the difference of the second and the first, so its coordinate formula is (−v,u+v); its inverse is (u+v,−u). For distinct p and q the unit direction is not needed: an equilateral completion is one of exactly the two rotations of q−p about p. Neither completion can be p or q. The point generator uses i = 0,…,n−1 and j = 0,…,n−1−i, including the sloping boundary. Both completions are tried for every unordered pair, and sorting and set insertion remove multiple enumerations of the same edge. There is no orientation, length, or rounding filter. The code’s triangle-count assertion is a check, not the geometric completeness argument. The closed form in [Brouwer et al., §1](https://arxiv.org/pdf/2405.12321v1) is n(n−1)(n+1)(n+2)/24 = binom(n+2,4).

**R2 — Exhaustive search (proof §2; verifier three).** Any proper coloring with at most three colors can be relabeled so that the origin is 0, and the rest of the root domains contain all three colors. Each deletion is forced: if the other two domains equal {c}, assigning c to the third vertex would create a monochromatic triangle. The implementation processes exactly the triangles incident to a pending singleton and checks both possibilities for the second same-color singleton, regardless of vertex order. At the root there is only one singleton. At a child, the inherited domains come from a parent whose queue has emptied, and the new branch singleton starts the queue. Any pair newly becoming singleton is detected no later than processing the later member; if a vertex has become singleton it remains so until the branch returns on an empty domain. Deleting a bit is guarded by checking membership, so it cannot add a color. Consequently pruning on an empty domain is sound. Every other node either reaches a complete assignment and checks it against all edges, or branches on every remaining color of one nonsingleton. Branch copies isolate mutations, including propagation. Each branch fixes a new point, so recursion is finite and has no unresolved resource or search cutoff. The tie-breaking order changes traversal only. The supplied log reports 216 origin-fixed models at order 8 (positive control) and zero at order 9 after 6,837 visited nodes and 3,436 conflict leaves. Order 8 is not a premise of the lower bound.
