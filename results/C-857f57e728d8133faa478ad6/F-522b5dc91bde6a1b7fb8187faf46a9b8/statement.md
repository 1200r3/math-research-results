# Exact classification of three-color shifted Schur equations

Let c_0,c_1,c_2 be nonnegative integers. Define R_3(c_0,c_1,c_2) as the least positive integer N such that every map chi:[1,N] -> {0,1,2} has x,y,z of some color i with x+y+c_i=z; if there is no such N, set R_3=infinity. Repeated inputs x=y are allowed; a color class may be empty.

If the three shifts are not all equal, R_3(c_0,c_1,c_2)=infinity. More strongly, writing s for the least 2-adic valuation of a nonzero pairwise difference of shifts, there is a coloring of all integers of period 2^(s+1) avoiding all three designated monochromatic equations. If the shifts all equal c, then R_3(c,c,c)=13c+14.

The diagonal formula is Schaal's; the present classification supplies the explicit nonconstant-shift construction.
