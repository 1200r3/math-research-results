# Public repository design

Target: 1200r3/math-research-results, independent history from the private collaboration repository.
English-first titles/abstracts, Chinese navigation, exact problem identifiers, per-result progress cards, readable PDF and TeX, Lean sources and pinned dependencies, citation metadata, two explicit license scopes, immutable accepted artifacts and versioned corrections.

Proposed GitHub topics: mathematics, number-theory, combinatorics, integer-partitions, laguerre-inequalities, quasi-polynomials, lean4, mathlib, formal-proof.
Topics and plain-text abstracts aid discovery; no guarantee of indexing time or ranking.

References consulted 2026-10-30:
https://github.com/teorth/pfr
https://github.com/google-deepmind/formal-conjectures
https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/classifying-your-repository-with-topics

Accepted release artifacts must be produced by release-prepare under results/<claim>/<fixed>/ and batches/<release> and linked from these reading pages. No copying of private repository history.
